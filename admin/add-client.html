API Key & Secret *
Getting your Upstox API Key & Secret
  1. Go to developer.upstox.com and sign in with your Upstox account
  2. Click My Apps → + Create New App
  3. Enter App Name (e.g. "MoneyMoose") and Redirect URL (e.g. https://moneymoose.co.in)
  4. After creation, your API Key is shown immediately — click "Show Secret" for the API Secret
TOTP Secret Key *
Getting your TOTP Secret Key
  1. Open the Upstox mobile app → Profile → Settings → Login & Security
  2. Tap 2-Step Verification → Set Up Authenticator App
  3. When the QR code appears, tap "Enter key manually" (small link below the QR code)
  4. The 32-character alphanumeric string shown is your TOTP Secret Key — copy it here
  5. If already set up: remove existing 2FA, then re-add to see the key again
Client ID & App ID *
Getting your Dhan Client ID & App ID
  1. Log in at web.dhan.co → click your profile icon (top right)
  2. Go to Profile → API & Data → DhanHQ Developer
  3. Click Create App and fill in App Name
  4. Your Client ID appears at the top of your profile page
  5. The App ID is shown on the created app detail page
TOTP Secret *
Getting your Dhan TOTP Secret
  1. Open the Dhan mobile app → Profile → Security Settings → 2-Factor Authentication
  2. Choose Authenticator App as your 2FA method
  3. When the QR code is shown, tap "Enter Key Manually"
  4. Copy the 32-character secret key displayed — paste it here
  5. Also scan it into Google Authenticator / Authy for your own login use
API Key & Secret *
Getting your Kite API Key & Secret
  1. Go to kite.trade/developer and sign up as a developer (₹2,000/month plan required)
  2. Click Create New App → fill in App Name and Redirect URL
  3. After creation, your API Key and API Secret are shown on the app detail page
  4. Note: Kite Connect tokens expire daily — you must re-run auth every morning before trading
TOTP Secret Key *
Getting your Kite TOTP Secret Key
  1. Open the Zerodha Kite mobile app → Profile → 2FA Settings
  2. Tap Set Up Authenticator App (TOTP)
  3. When the QR code appears, tap "Enter Manually" or "Can't scan?"
  4. Copy the 32-character key shown — that is your TOTP Secret Key
  5. Also add it to Google Authenticator / Authy so you can log in to Kite yourself
